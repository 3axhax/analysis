# Коррекция DB-эталонов RDW

Дата: 2026-10-14. Пользователь явно запросил исправить подготовленные JSON из БД. Основание: rdw в БД означает RDW-CV/RDW; для RDW-SD соответствия нет.

Удалить только 8 неподдерживаемых записей из DB-results: явный SD в doc-03/04/05/10/13/17; «Ширина распределения эритроцитов» с фл в doc-06/12. Классификация производится независимо от matcher по имени и единице подготовленного source JSON; это подготовка oracle, не runtime unit parsing. CV/RDW и остальные записи, значения, units и порядок сохранить. PDF не перечитывать, source/Python JSON не менять.

Перед изменением сохранить recoverable копию DB-results в ignored локальном каталоге с ограниченными правами; backup БД также создан и проверен. Новый snapshot `.nest-benchmark-rdw-cv` наследует каталог и frozen baseline от chloride и старое независимое expected; исключить те же индексы SD, унифицировать variants rdw как cv, обновить только fingerprints DB-эталонов. Input fingerprints и sourceCount не переписывать. Старые snapshots сохранить.

Проверки: 17 валидных DB JSON, правильные keys/types, точное сохранение всех не-SD записей и порядка, 8 исключений, неизменность source/Python JSON, Git-ignore и права. Corpus по новому oracle с явным разделением changed-input skips, без сравнения нового знаменателя со старым без оговорки. Rollback — восстановить локальную копию DB-results, выбрать старый snapshot, не менять БД.
