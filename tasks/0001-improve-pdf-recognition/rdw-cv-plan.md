Дата: 2026-10-14. По предметному уточнению пользователя запись rdw соответствует RDW-CV, а RDW-SD не поддерживается. Read-only проверка живой БД: translationParsing содержит rdw и «Распределение эритроцитов по объему», SD aliases отсутствуют. Поэтому БД не менять, исправить ошибочный расширенный словарь кода. Backup проверен.

План: убрать SD alias, исключать rdw для явно SD-имени до группировки кандидатов, унифицировать варианты RDW/RDW-CV как cv; неподдерживаемая SD-запись даёт предупреждение и не блокирует CV. Одинаковые значения RDW/CV объединять, разные оставлять конфликтом. Маркер SD в референсной прозе после результата не должен блокировать CV. Python, API, units и БД не меняются.

Проверки: synthetic name/value и matcher tests, corpus текущим неизменным expected (с обязательной оговоркой: старые DB-эталоны ошибочно содержат SD, поэтому не медицински корректный acceptance denominator), tests/build/lint/health.
