# Сверка показателей статей с локальной БД

23.11.2026. Сопоставлены ID из девяти страниц `/analizy/<slug>/` и локальной таблицы `analysisPoint`. Для проверки состава типов анализов использованы `analysisType` и `analysis_type_point`. Запросы выполнялись в режиме read-only.

На страницах 65 уникальных ID из 67 записей статического справочника. В БД 100 показателей. Совпали 64 ID, названия всех 64 совпали с названиями в статическом справочнике до форматирования заголовков страницы. Все 65 ID страниц разрешаются в статическом справочнике.

## Есть на странице, отсутствует в БД по ID

В разделе печени выводятся и устаревший ГГТП (ID 35), и действующий ГГТП (ID 62). Миграция [0035](../../server/src/migrations/ggtp-point-consolidation.sql.ts) объединила эти записи. По смыслу показателя, отсутствующего в БД, нет.
