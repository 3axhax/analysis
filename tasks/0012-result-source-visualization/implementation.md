# Реализация

Выбор корневых источников работает через `react-select`; выбранные общие и внешние описания выводятся одной существующей таблицей и сортируются по количеству условий. Для внешних нормативов рядом с показателем показан значок информации; у явно унаследованных общих нормативов значок отсутствует. При наведении/фокусе доступно краткое название, по клику — карточка с метаданными, ссылкой на документ и лицензией; закрытие — повторный клик, указатель вне карточки или Escape. Ссылки ограничены HTTP(S). При отсутствии выбранных источников таблица показывает пустое состояние.

API и БД не менялись. Проверки: три синтетических клиентских теста на сортировку, наследование, фильтр и карточку; client lint/build прошли. В отдельном временном браузерном экране с синтетическими данными проверены вид таблицы, карточка и отключение источника; временный экран удалён. Медицинские значения, реальные ссылки результатов и ID в задаче не фиксировались.
