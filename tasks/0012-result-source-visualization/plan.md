# Визуализация источников интерпретаций

## Цель и границы
Перенести выбор источников в мультиселект, объединить общие и внешние описания в существующей таблице, сортируя по числу условий. У внешних, не унаследованных нормативов отображать интерактивную информацию об источнике. API, медицинскую логику и БД не менять.

## Текущее состояние и решение
`AnalysisResultPage.tsx` выводит внешние описания отдельно; `AnalysisDescriptionList.tsx` показывает общие описания и статусы. Использовать существующий `react-select` и объединить данные в одну таблицу. Источник принадлежит отдельному описанию; `inheritedPointIds` исключает значок для общих нормативов. Тултип по hover/focus, закрепляемая карточка по клику с закрытием снаружи и Escape; видимые метаданные и ссылки с разрешёнными URL сохраняют атрибуцию.

## Проверки и риски
Client build/lint; тесты сортировки, фильтра, статуса и признака наследования при необходимости; браузерная проверка без фиксации чувствительных значений, ссылок и ID. Не менять сохранённые результаты или общие нормативы; пустой выбор не отображает описания. Проверить доступность с клавиатуры и мобильную компоновку.
