# Реализация

Внешние описания показываются с существующим маркером списка и кнопкой «Источник» внизу справа. Кнопка использует общий InfoPopover: краткая подсказка при наведении, полные сведения по клику, закрытие вне окна или по Escape. Автоматическое закрепление при наведении удалено для всех тултипов. Служебная фраза о статусах скрыта только в отображении внешних описаний точным совпадением; сохранённые данные, API и медицинские условия не менялись.

Проверка: client build и lint прошли, 7 профильных тестов прошли локально; на открытой странице проверены список, отсутствие фразы и открытие сведений об источнике. В dev-контейнере Vitest не установлен, тесты выполнены с локальными зависимостями проекта. Сборка вывела существующие предупреждения CSS и размера bundle.
