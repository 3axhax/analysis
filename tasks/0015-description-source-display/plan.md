# Отображение источника интерпретаций

Цель: единый стиль списков, ссылка «Источник» в ячейке описания внешнего источника и закрепление тултипов только по клику. Убрать из отображения фразу о статусах. Использовать существующие Table, InfoPopover и стили списков; данные БД, нормативы и вычисления не менять.

Текущая реализация: AnalysisDescriptionList показывает внешние описания текстом и SourceInfo только около отдельных показателей; InfoPopover поддерживает таймер. Фразу из сохранённого текста скрыть в представлении, сохранив БД; исключить только точную служебную фразу. Источник описания оставить доступным даже при наследованных нормативах.

Проверка: тесты рендеринга, hover/click/outside, сборка и lint клиента, smoke страницы результата. Риски: не менять смысл медицинских интерпретаций и не выводить данные результатов в отчётах.
