# Baz и соавт. — приложения PLOS ONE

Проверено 19.11.2026. Основной набор для сервиса — SI-границы таблицы 3 опубликованной статьи. Приложения сверены для проверки единиц, выборки, решений о разбиении и возможных дополнительных референсов. [Статья и материалы издателя](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0236772#sec018).

| Материал | Что установлено | Значение для сервиса |
| --- | --- | --- |
| [Рисунок S1](https://doi.org/10.1371/journal.pone.0236772.s001) | Сравнение панели сывороток с приписанными значениями в лабораториях Каира и Александрии. | Подтверждает происхождение согласованного набора. Точки и линии измерений не являются границами интервалов. |
| [Рисунок S2](https://doi.org/10.1371/journal.pone.0236772.s002) | Распределения по полу и возрасту. Ящик показывает центральные 50% наблюдений. Примечание указывает, что вторичного отбора LAVE для графиков не проводили. | Границы и возрастные разбиения берутся из итоговой таблицы 3, а не из крайних точек или коробок рисунка. |
| [Рисунок S3](https://doi.org/10.1371/journal.pone.0236772.s003) | Сравнение севера и юга Египта по ИМТ и пяти показателям. Для общего и прямого билирубина оси подписаны в мкмоль/л. Нижняя правая панель подписана HDL-C, в подписи к приложению на странице статьи указан LDL-C. | Единицы билирубина дополнительно подтверждены. Конкретный липопротеин по спорной панели не использован. Отдельных региональных пределов для переноса нет. |
| [Таблица S1](https://doi.org/10.1371/journal.pone.0236772.s004) | Аналитические методы, прослеживаемость и междневные коэффициенты вариации по лабораториям. Для ОЖСС измеряли разные исходные величины, для LDL-C описано измерение или расчёт в зависимости от концентрации триглицеридов. | Сохраняется происхождение существующих пределов. Методика получения измерения не задаёт отдельного диагностического правила. |
| [Таблица S2](https://doi.org/10.1371/journal.pone.0236772.s005) | Агрегированные характеристики выборки. В строке возраста 320 мужчин и 364 женщины, знаменатели по другим признакам отличаются. В основном тексте указано 691 набранных. | Для каждого интервала использовать число наблюдений его строки. Разницу между числом набранных и знаменателями анкеты не интерпретировать как число исключений из всех анализов. |
| [Таблица S3](https://doi.org/10.1371/journal.pone.0236772.s006) | Половые, общие оценки и варианты с LAVE и без него. У общего и прямого билирубина явно указано µmol/L. Мужская строка общего билирубина без LAVE даёт 2,522–20,585, женская 2,242–12,392. Для прямого билирубина это 0,618–6,309 и 0,449–3,648. | Подтверждает округлённые пределы и единицы четырёх уже внесённых строк таблицы 3. Альтернативные оценки не заменяют выбранные авторами. |
| [Таблица S4](https://doi.org/10.1371/journal.pone.0236772.s007) | Проверены все метки возрастного столбца. В опубликованном файле только общий набор 18–65 лет и разбиения около 45 лет. В ответе рецензентам упомянуто отдельное использование данных старших участников, но числовых пределов для обособленной группы старше 65 лет в таблице S4 нет. | Совпадение возраста 45 разрешено уже внесённым разбиением. Оснований расширять область после 65 полных лет нет. |
| [S1 Data](https://doi.org/10.1371/journal.pone.0236772.s008) | Исходный набор указан у издателя отдельно от таблиц референсов. | Индивидуальные строки не обрабатывались. Референсы автора сверялись по опубликованным агрегированным таблицам, повторное статистическое исследование исходного набора не требовалось. |
| [Замечания рецензента](https://doi.org/10.1371/journal.pone.0236772.s009) и [ответы авторов](https://doi.org/10.1371/journal.pone.0236772.s010) | Уточнены транспортировка панели, сопоставление двух лабораторий, использование регрессии для части показателей и роль выборки старше 65 лет. Приложенные к ответам рисунки касаются стабильности и сдвига измерений. | Ответы поясняют методы и ограничения. Нового согласованного табличного набора для сервиса в них нет. |

Итог. Сверка всех опубликованных приложений с агрегированными результатами и материалов рецензирования завершена. Для уже импортированных референсов изменений не требуется. Не предложены дополнительные интервалы старше 65 лет и региональные правила. Запись в журнале переведена в «анализ проведён».
