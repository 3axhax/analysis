# Инсулин и сочетания липидограммы и углеводного обмена

По решению пользователя изменить общий референс инсулина на 2,6–24,9 мкЕд/мл для всех возрастов и полов. Существующая единица `mUnit/l` эквивалентна мкЕд/мл; сохранить также ввод мкЕд/л с точным пересчётом 1000:1, не изменяя другие показатели и независимые источники. Защитить существующие значения и снимки результатов; при отсутствии нормы старые снимки продолжают использовать свои данные. Значения глюкозы, гликированного гемоглобина и С-пептида не изменять.

Добавить семь сочетаний из таблиц методички, игнорируя степень повышения согласно решению пользователя. Сохранить тексты методички без новых формулировок; условия, связанные с неуказанной границей возраста и отсутствующим HOMA, реализовать после уточнения пользователя. Текущая оценка HOMA не предусмотрена. Проверить отсутствие дубликатов, точные условия, источники, единицы, пограничные значения и оба пола, rollback и повторное применение. При изменении БД — проверенный дневной backup, guarded dry-run, транзакция, marker и тесты; не читать сохранённые результаты и не выводить ссылки. Откат только при отдельно согласованном обслуживании.

Уточнение пользователя: липидное сочетание применять для любого возраста; добавить расчёт HOMA и проверять его норму для соответствующего сочетания. Референс HOMA 0–2,7 из методички применяется для всех существующих возрастных групп. Из текста одного правила убрано слово «незначительном» по решению не учитывать степень повышения; ранее согласованное удаление вводного «возможно» также сохранено.
