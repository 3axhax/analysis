# Реализация

Общие нормативы инсулина перенесены на 2,6–24,9 мкЕд/мл (эквивалент мЕд/л) во всех существующих возрастах и для обоих полов. Сохранён ввод мкЕд/л; точечные коэффициенты преобразования равны 0,001 и 1000. В алиасы добавлено мкЕд/мл. Исправлена неверная подпись единицы мкЕд/л, ранее отображавшейся как мкЕд/мл. Сохранённые измерения, снимки и независимые источники не переписывались.

HOMA-IR рассчитывается как глюкоза в ммоль/л × инсулин в мкЕд/мл / 22,5 при наличии обоих допустимых измерений; расчётное значение не сохраняется как введённое измерение. Общий референс 0–2,7 добавлен для всех возрастов и полов, точное значение сравнивается до округления. При отсутствии или неподдерживаемых единицах расчёт не выполняется. Не предусмотрена проверка условий сдачи анализов.

Добавлены семь правил из таблиц методички: два сочетания липидов и пять сочетаний углеводного обмена. Степень повышения не учитывается; липидное правило действует для всех возрастов. Одно сочетание дополнительно требует нормальный рассчитанный HOMA. Тексты следуют методичке с исключением вводного «возможно» и обозначения незначительной степени повышения по указанию пользователя. Глюкоза, гликированный гемоглобин и С-пептид не изменены.

Применены атомарные миграции 0046–0048 с проверками исходного состояния и отдельными markers; предварительно выполнен dry-run с откатом на существующей локальной БД и использована проверенная копия за текущий рабочий день. Backend build и 447 тестов прошли. Через обычный API проверены семь сочетаний и отрицательный случай HOMA, по 16 случаев граничных значений инсулина и три случая граничных значений HOMA, оба варианта единицы инсулина. Индивидуальные результаты и capability-ссылки не выводились.
