# Пересекающиеся возрастные диапазоны

- Хранить все возрастные диапазоны в `ages` и определять применимость по сохранённому `ageInDays` при чтении.
- Удалить `analysisResult.ageId`. Сохранить сами результаты и их измерения.
- Перенести область источника в связи с `ages`. Перепривязать интервалы, связанные условия и расчётные показатели к соответствующим диапазонам.
- Проверить конфликтующие референсы при пересечении диапазонов одного источника. Независимые источники могут показывать разные референсы.
- Проверить миграцию с откатом и применить локально. Проверить обычные API на синтетических данных.
