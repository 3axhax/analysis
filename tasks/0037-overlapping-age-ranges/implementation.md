# Пересекающиеся возрастные диапазоны

Возраст сохраняется только в `analysisResult.ageInDays`. При чтении выбираются все строки `ages`, в которые входит возраст в днях. Массив идентификаторов применяется к интервалам показателей, их отображению, расчётным значениям и подбору описаний. Для измерения сохраняется один набор совпадений. Диапазоны независимых источников могут показываться одновременно. Для одинакового общего референса из нескольких групп выдаётся одна строка.

Миграция `0067-overlapping-age-ranges` создала таблицу `medicalSourceAge` со связями источника с `ages`. Существующие ссылки `allowedAgeIds` мигрировали напрямую. Для `minAgeDays` и `maxAgeDays` используются существующие записи с теми же границами или создаются новые. Открытые границы ограничены действующей областью ввода, которая при миграции составляла 0–72 000 дней. Возрастные ключи удалены из метаданных. `derivedPoint` остаётся в метаданных как признак расчётного показателя, NLR использует возрастную связь источника.

Дубли внешних интервалов объединены только при полном совпадении показателя, пола, единицы, границ, операторов и статуса внутри источника. Перед объединением проверено покрытие целевого диапазона исходными возрастами, в том числе для каждой связанной интерпретации. Сохранён один ID интервала, связи перенесены. Если покрытие неполное, миграция откатывается. Из `analysisResult` удалена колонка `ageId`; прежние результаты и измерения сохранены.

Редактор интервалов выявляет разные референсы NORMAL или OPTIMUM одного источника, показателя, пола и единицы при пересечении возрастных диапазонов. Также выявляет пересечение LOW и HIGH между такими группами, включая точку границы при включении с обеих сторон. При конфликте API возвращает 409. Миграционный аудит подтвердил отсутствие конфликтующих референсов между разными возрастными группами в проверенной БД.

## Проверка

Dry-run выполнен с откатом. Миграцию применил штатный запуск локального backend. Проверены 36 возрастных связей для 33 источников, отсутствие возрастных ключей в метаданных, удаление колонки результата и сохранение всех 246 прежних результатов и 1 149 измерений до добавления синтетических проверок. Объединены 1 029 дублирующих копий интервалов, 757 интервалов перепривязаны, условий без интервалов нет.

Прошли 467 серверных и 27 клиентских тестов, TypeScript и 30 проверок через обычные локальные endpoints. На синтетических результатах проверены детский и взрослый NLR, переходы неонатальных и взрослых возрастных границ, работа двух внешних и общего референсов одновременно, условия описаний и отсутствие прежнего поля в API. Запрос проверки конфликта дополнительно выполнен read-only на синтетическом диапазоне.

Откат после применения требует отдельной миграции восстановления прежней схемы и связей. Production не изменялся.
