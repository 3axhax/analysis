# Иллюстрации групп статей

Цель: подготовить единый визуальный ряд для 13 групп на странице «Статьи». Текущий этап по запросу пользователя — только одна иллюстрация первой группы и её вставка в карточку-ссылку.

Первая группа по миграции каталога: «Общий анализ крови с лейкоцитарной формулой и СОЭ», alias obshchiy-analiz-krovi. Сейчас ArticlesPage.tsx выводит только текстовые ссылки сеткой в 1/2/3 колонки.

Решение: спокойная редакционная иллюстрация клеток крови и лабораторной пробирки без текста, в цветах сайта; сохранить растровый оригинал и оптимизированный WebP в client, сопоставить изображение по стабильному alias. Картинка входит в существующую ссылку, заголовок остаётся текстом. Для остальных 12 групп изображения пока не генерировать.

Этапы: генерация через встроенный image_gen, осмотр, сохранение в репозиторий, интеграция первой карточки, build/lint и просмотр во встроенном браузере.

API, БД и медицинские трактовки не меняются. Не использовать реальные бланки и персональные данные. Иллюстрация декоративная, без диагностических утверждений. Миграций нет; откат — удалить привязку и добавленные assets. Приёмка: первая карточка содержит изображение, ссылка и адаптивная сетка работают, остальные карточки сохраняются. На сервер не публиковать без запроса.

Уточнение реализации: оптимизированный asset — JPEG (960×640), штатный sips; WebP-кодировщик отсутствует, дополнительные зависимости не устанавливались. Оригинал PNG сохранён в output/imagegen.

## Продолжение по запросу пользователя
Сгенерировать остальные 12 изображений в стиле первой иллюстрации. Один отдельный вызов image_gen на группу, единый формат 3:2, без текста; исходники сохранять в output/imagegen, JPEG 960×640 — в shared/assets/article-groups. Привязка по alias. Проверить наличие image/url/headline во всех 13 Article, build/lint и встроенный браузер.
