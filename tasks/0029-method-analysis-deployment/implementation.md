# Состояние поставки

Задача анализа принята; незавершённый анализ мочи отмечен в журнале. Коммит `fc0540d` отправлен в `origin/main`; серверный checkout `/var/analysis/analysis` обновлён до него через `git pull --ff-only`, локальные конфиги, загрузки и работающие контейнеры сохранены. Слияние не потребовалось. Полный набор 454 серверных тестов, сборки сервера и клиента и клиентский lint прошли.

Запуск новых контейнеров не выполнен: сначала нужно проверить 35 последовательных startup-миграций на совместимость с production. Запланированный dry-run в транзакции с временными счётчиками отклонён автоматической проверкой из-за риска эксклюзивных блокировок рабочих таблиц и временных изменений данных. Пользователь отказался от создания отдельной тестовой БД. Публичный API health продолжает отвечать; работающий backend остаётся прежним. Данные и процессы production не изменялись, кроме обновления checkout.

Позднее пользователь явно разрешил сухой прогон; после одобрения все 35 миграций прошли в одной транзакции с откатом и временными счётчиками. Post-check подтвердил прежние маркеры и 13 исходных измерений ГГТП. При последующей сборке двух образов доступность API и SSH нарушилась. Локальное соединение сборки прервано; API отвечает нестабильно, SSH не позволяет подтвердить завершение серверной сборки. Переключение контейнеров и применение миграций не запускалось. Поставка не завершена.

После восстановления SSH выяснилось, что прежние контейнеры клиента и backend остановились, сайт отвечал 502. Они запущены повторно, Nginx проверен и перезагружен; главная и API health вернули HTTP 200. Работает прежняя версия; новые образы отсутствуют. На сервере около 1,9 ГиБ RAM без swap, доступно около 558 МиБ. До выбора безопасного способа сборки повторять прежний запуск рискованно: он уже сопровождался недоступностью сервиса.

В согласованное окно backend и клиент последовательно собраны из checkout fc0540d с отдельным сборщиком BuildKit, ограниченным 512 МиБ, и сохранены под тегами fc0540d. После сборки запущены прежние контейнеры; главная и API health отвечают HTTP 200. Новые контейнеры не запускались, миграции не применялись. Свободно 2,8 ГиБ на диске; до переключения требуется оценить место и совместимость возврата старого backend после миграций. Сборка клиента сообщила о двух предупреждениях CSS и 28 находках npm audit, включая 3 critical.

Поставка завершена: checkout /var/analysis/analysis и origin/main на fc0540d, оба работающих образа имеют тег fc0540d. Startup-миграции 0018–0052 применены и подтверждены 35 маркерами; агрегатно подтверждено отсутствие старого id ГГТП и ссылок на него. Главная, JS asset, health и каталог возвращают HTTP 200, неавторизованный admin endpoint — 403. Синтетический save/get для ионизированного кальция подтвердил единицу, границы и NORMAL (код -1); первичная проверочная команда ошибочно не включала -1 в ожидаемые коды. Синтетическая запись оставлена в БД, её capability ID не записывался. PostgreSQL и PDF-сервис не перезапускались.
