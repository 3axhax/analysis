# Приёмка и доставка изменений анализа методички

Принять задачу 0018 в текущем объёме: сверка остановлена по решению пользователя, общий анализ мочи не завершён. Проверить состав незакоммиченных изменений и историю, исключить секреты и пользовательские данные, выполнить проверки затронутых компонентов и `git diff --check`, закоммитить связанные изменения. Получить актуальный origin, при необходимости интегрировать main без перезаписи чужой работы, проверить и отправить согласованный commit.

Перед production изучить текущий checkout, dirty state и compose, доступность базы и pending startup migrations. Из-за многочисленных миграций с точными предусловиями выполнить проверку на production данных без изменения рабочих строк: последовательный SQL dry-run в одной транзакции с обязательным откатом, без публикации чувствительных данных и без копирования дампа. При несовпадении предусловий исправить миграции или остановиться до перезапуска; не переписывать production результаты ради локальных допущений. Затем обновить checkout через `git pull --ff-only origin main`, собрать только затронутые client/server контейнеры и проверить их, публичный health и версию. Не перезапускать БД/PDF/Nginx без необходимости. Существующие server конфиги, uploads и данные сохранить; следовать DEPLOYMENT.md. Дополнительные backup не создавать без отдельного запроса, согласно указанию пользователя и документации.
