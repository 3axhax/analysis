# Переход на интервальную логику

Проверить и удалить альтернативную старую логику нормативов, статусов и расшифровок, включая переключатель режима, не изменяя PDF-парсер. Проверить зависимости действующих маршрутов, административных функций, unit conversion, моделей и тестов. Исторические миграции исследовать отдельно: они могут понадобиться для последовательного обновления существующих баз и не являются действующей логикой обработки результата.

Провести read-only ревизию схемы БД и удалить остатки старой модели нормативов, статусов и расшифровок, если они обнаружатся. В локальной БД таблицы analysisPointMinValue и analysisPointMaxValue уже отсутствуют, интервальная таблица существует, миграция 0056 зарегистрирована. Перед любыми дополнительными изменениями БД уточнить область и зависимости, выполнить проверку на копии и действовать согласно правилам миграций.

Сохранить незавершённые изменения задачи 0033. Использовать проверенную резервную копию начала дня. Проверить синтетическими тестами все границы интервалов, единицы, описания, авторизацию и маршрут чтения, собрать backend, затем выполнить сквозную проверку API без вывода сохранённых результатов или ссылок.
