Перед изменением создан/проверен новый backup, БД не менялась.

В AnalysisPointSelectedItem select показывается только при нескольких доступных единицах. При одной подтверждённой единице показана обычная текстовая подпись. Если unit не распознана, единственный вариант не назначается автоматически: показано «Единица не определена» и кнопка явного подтверждения. Нулевые/дробные значения и исходная единица сохраняются; ручная смена unit не пересчитывает число.

Добавлен презентационный unitLabel в entities/units/lib/unit-label.ts: русские обозначения16 текущих units и известных вариантов написания, без изменений name/code/ID в API или БД. Исходное обозначение имеет приоритет: ng/ml становится нг/мл, а не равнозначной мкг/л; g/dl становится г/дл, а не г/л. Неизвестные подписи оставляются без угадывания размерности. Это UI-словарь, не источник aliases для распознавания и не таблица коэффициентов. Admin поля технических name/code/parsing не переименованы.

Форматтер применяется в форме выбранных показателей, общем селекторе единиц, результатах/границах/расчётной подсказке и admin просмотре нормативов. Изменения серверного алгоритма, БД и gold не потребовались.

Client container build/lint успешны. Ранее существовавшие CSS и chunk warnings сохраняются. Ручного браузерного smoke не было.
