# Восстановление локальных сервисов

Цель: восстановить dev API, client и PDF parser после обновления Git. Изменения прикладной/медицинской логики не планируются.

Диагностика: чистая рабочая копия; старый backend node_modules не содержит @nestjs/axios, axios, decimal.js. PDF контейнер отсутствует. В рабочей БД отсутствуют ручные миграции 0002, 0003, 0006 и startup marker add_parsingOrder_to_analysisPoint.

План: проверить backup, остановить backend, установить lockfile dependencies, собрать и запустить parser; подготовить миграции и получить отдельное разрешение на работу с БД. После разрешения проверить up/repeat/down на disposable копии, сравнить counts/constraints, применить необходимые миграции и запустить backend. Проверить health и read-only справочники, build и тесты. Не создавать результаты в рабочей БД.

Область БД: parsingOrder в analysisPoint; 0002 добавляет единицы, aliases, правила конверсии, source/provenance поля и ограничения; 0003 разрешает исходную единицу ferritin; 0006 расширяет CHECK для source-only. Нормативы и сохранённые результаты не переписывать. Rollback: штатные down в обратном порядке, только при выполнении guards; старый код/backup сохраняются. Реальные данные и содержимое backup не публиковать.

Критерий: client/API/parser отвечают, справочники читаются, схема совместима с текущим кодом, данные результатов сохранены. Подтверждение БД обязательно по AGENTS.md.
