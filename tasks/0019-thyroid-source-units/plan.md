# Единицы FT3/FT4 в источниках задачи 16

Проверить статьи Moran и Van Uytfanghe, действующие общие и источниковые нормативы FT3/FT4, связи наследования и преобразования единиц. Не принимать клинические случаи статьи за универсальные референсы. Сохранить историю измерений, общие нормативы и другие источники; данные менять только при доказанной необходимости через миграцию после отдельного подтверждения. Проверить синтетическими тестами наследование, оба пола, границы и обе единицы; предметная проверка специалиста не заменяется автоматическими тестами. Локальная резервная копия создана и её каталог проверен до начала задачи.
