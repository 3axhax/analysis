# Сверка описаний с методичкой

По запросу пользователя убраны добавленные мной повторы статусов и общие оговорки; формулировки приведены ближе к смыслу методички, с условными словами вместо категоричных диагнозов. Приоритет отдан ранее изменённым мной записям, включая сочетания крови, железа, белка и белковых фракций, мочевины, билирубина и коэффициента де Ритиса. В частности, восстановлена интерпретация железодефицитной анемии для описаний комбинаций ОАК; в списке мочевины восстановлены детали причин, опущенные при моей предыдущей редакции. Тексты не повторяют данные, уже показанные в условиях. Ранее сохранённые пользователем 51, 92 и 95 не менялись.

Миграция `0039-source-description-revision` атомарно обновляет 42 общих описания, защищена проверкой прежних текстов и ожидаемого числа совпадений. 314 условий и 12 записей независимых источников до/после проверены на идентичность внутри транзакции; идентификаторы и правила не менялись. Для коэффициента существующие LOW/HIGH тексты приведены к соответствующим строкам источника; строка с порогом ≥2 не включена, так как статус HIGH начинается выше 1,75 и не определяет числовой порог. При текущем механизме для значения 2 она не выводится. Градации, их перекрытия и предлагаемое кодовое решение документированы в `de-ritis-gradations.md` и пока не реализованы: пользователь просил предложение.

Проведены визуальная сверка выбранных таблиц стр. 14–15, 20, 22–28, 35–36 и работа с отчётами ранее выполненной сверки, повторно просмотрены затронутые авторской редакцией описания и условия. Для 97 общих описаний ID 1–98 выполнен автоматический скрининг совпадения слов с текстом соответствующих разделов в оперативной памяти без сохранения и вывода текста методички; низкое совпадение двух коротких записей дополнительно проверено. Такой скрининг не доказывает пословного совпадения и не заменяет полного повторного построчного медицинского аудита всех формулировок. На этапе 0039 независимые источники не менялись; последующая отдельная сверка и изменение семи источниковых текстов описаны ниже.

Проверены читаемость существующего backup рабочего дня, dry-run с ROLLBACK, сохранность условий и source descriptions, отсутствие невалидированных constraints, marker, синтетический HTTP save/get изменённого описания без вывода capability ID, полный backend suite 409 тестов / 50 наборов и backend build. Дополнительно создан один локальный синтетический результат. Production не менялся. Откат — отдельное согласованное обслуживание с учётом startup migration marker; не удалять пользовательские данные ради отката.

## Дополнительная проверка пунктов и независимых источников

Проведён второй автоматический скрининг отдельных пунктов 97 общих описаний; семь записей с неполным совпадением проверены визуально по соответствующим страницам. Миграция `0040-source-description-typos` исправила склеенный пункт и опечатки в четырёх общих описаниях без изменения условий. Автоматический скрининг не является полной пословной проверкой или клинической валидацией.

Семь уже рассматривавшихся описаний трёх независимых источников о дефиците железа и анемии также проверены по собственным источникам, а не по методичке. Миграция `0041-source-description-concision` убрала повтор показателей и общие оговорки, сохранив важное ограничение применимости порога для женщин и ссылки на источники. Проверены [Soppi](https://pmc.ncbi.nlm.nih.gov/articles/PMC5986027/), [Gibson и Friel](https://nutritionalassessment.org/iron/) и [Begum и Latunde-Dada](https://pmc.ncbi.nlm.nih.gov/articles/PMC6835368/). В rollback dry-run 314 условий и все 175 привязок описаний к источникам сохранены. Это дополнение изменяет тексты семи независимых описаний; предыдущая запись о неизменности source descriptions относится только к миграции 0039.

После 0040/0041 повторно прошли 409 backend тестов и backend build. Обычный API на ещё одном синтетическом результате подтвердил как общее описание ОАК, так и источниковую интерпретацию; содержимое реальных результатов и ссылки не выводились. Синтетический результат остался в локальной БД. Источники/референсы, условия и медицинские данные пользователей не изменялись; клиническая экспертиза текстов не проводилась.
