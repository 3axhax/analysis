# Градации натрия

Добавлены источник Schwarz и три биохимические градации: <125, ≥125 и <130, ≥130 и <135 ммоль/л, все со статусом LOW и отдельным описанием. Границы для дробных значений уточнены по https://pmc.ncbi.nlm.nih.gov/articles/PMC11828805/ и согласованы пользователем. Значения ≥135 не объявляются нормой по данному источнику. Создано по одному интервалу для каждой комбинации имеющихся возрастов и полов; существующие нормативы и результаты не изменялись.

Миграция 0057 атомарно создаёт источник, 180 интервалов, три описания, условия и связи. Зарегистрирована после миграции модели интервалов; marker предотвращает повторное выполнение. Для отката требуется отдельное согласование и проверка зависимостей, удаление данных автоматически не выполняется. Проверенная резервная копия находится вне Git.

На изолированной восстановленной копии проверены применение, откат транзакции, количество записей и синтетические пограничные значения 124,9, 125, 129,9, 130, 134,9 и 135. Локально проверены marker и количества; сборка backend прошла. Профессиональная клиническая экспертиза отдельно не проводилась.

Полный набор тестов при выключенном интервальном режиме: 518 успешно. При включённом режиме 13 старых тестов чтения завершаются ошибкой; остальные 505 проходят. Сквозная проверка HTTP с синтетическим результатом не выполнялась.

Последующее уточнение: в задаче 0034 старая ветка чтения удалена, а полный набор актуальных backend-тестов прошёл. Синтетическая сквозная проверка HTTP подтвердила сохранение и умеренную градацию натрия.
