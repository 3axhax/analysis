# Белый экран при возврате на главную

Исправить цикл обновлений между локальными selectedOptions и Redux selectedList в AnalysisPointGroupSelect. При монтировании AnalysisPage родитель сбрасывает выбор, а эффекты дочернего селектора отправляют прежнее состояние обратно.

Решение: Redux — единственный источник выбранных ID; options вычисляются при render, dispatch выполняется только в пользовательских обработчиках. Сохранить групповой выбор, распознавание и удаление параметров; не удалять неизвестные ID при задержке справочника.

Проверка: тест монтирования с непустым выбором и родительским reset, внешние изменения Redux и обновление справочника; build и lint клиента. Использовать только синтетические данные. Backend/БД и production не менять.

## Согласованная поставка

Пользователь запросил commit, push, merge в main и обновление рабочего сайта. После повторных проверок зафиксировать исправление и документацию предыдущей поставки, отправить ветку и слить в main. Production: собрать только client из нового release с действующим client env; сохранить предыдущий client image для отката, переключить только client_analysis и reload Nginx. Backend, Python, PostgreSQL и миграции не запускать и не менять. Проверить HTTPS, API health, доступность нового JS bundle и неизменность остальных контейнеров.
