# Журнал проверенных внешних статей

Перед началом работы проверь журнал; при изменении результата обновляй запись. Статусы: «анализ проведён», «частичный анализ», «не подходит по лицензии», «не подходит: права не подтверждены». Проверку доступных сведений о правах заверши сразу; если права не подтверждены, статью отклони. Частичный анализ продолжай только для статей с подтверждёнными правами. Подробности и предложения остаются в задаче. Исторические записи помечены частичными, когда полнота анализа по новой методике не подтверждена.
