# Дополнительный поиск по четырём русскоязычным журналам

## Охват

Оглавления издателей использованы для отбора статей с 2020 года. Подборка ограничена 20 кандидатами на журнал. При отборе учитывались исследование лабораторных показателей, наличие порогов и возможность применять данные в текущей форме. Статьи, уже зарегистрированные в источнике, исключены.

Для 40 статей с CC BY 4.0 сверены полные тексты. Двадцать статей источника 346 остановлены на проверке прав. Пункт 1.3 [договора издателя](https://molmedjournal.ru/ru/rules) указывает CC BY-NC-ND 4.0. В карточках этих статей отдельные разрешения на коммерческую адаптацию не обнаружены. Все четыре журнала оставлены в `PARTIAL`, поскольку проверка полных текстов ограничена подборкой. Названия, годы выпуска, DOI, лицензии и выводы по каждому кандидату находятся в `medicalSource`.

## Применённые данные

- Из [лекции Морозовой и соавторов](https://mednauki.ru/index.php/MK/ru/article/view/1340) добавлено пояснение о возможной перегрузке железом. Условия для мужчины от 18 лет — насыщение трансферрина **>50%** и сывороточный ферритин **>300 мкг/л**. Оба показателя обязательны. Пороговые интервалы без статуса используются как условия интерпретации. Генотип и наличие перегрузки по двум показателям не устанавливаются. У женщин рекомендации различают статус менопаузы, которого нет в сервисе. [Проверка по руководству EASL](https://easl.eu/wp-content/uploads/2022/06/PIIS01688278220021121.pdf)
- Из [обзора Смирновой и соавторов](https://www.sci-notes.ru/jour/article/view/949) добавлено пояснение о различии концентрации холестерина ЛПВП и функции этих частиц. Условие привязано к существующим общим интервалам со статусом HIGH у взрослых. Обзор не задаёт свой числовой порог. [Полный текст](https://pureportal.spbu.ru/files/115587908/949_3592_1_PB.pdf)
- В справочнике появились **насыщение трансферрина железом (TSAT, %)**, **С-реактивный белок (СРБ, мг/л)** и **прокальцитонин (нг/мл)**. Для них добавлены английские названия и фразы PDF-парсинга. Прокальцитонин распознаётся по названию. Самостоятельное сокращение PCT исключено из алиасов из-за возможной путаницы с тромбокритом. Числа для СРБ и прокальцитонина из работы Дроздова и соавторов относятся к четвёртым суткам после панкреатодуоденальной резекции. [Материалы и таблицы исследования](https://mednauki.ru/index.php/MK/ru/article/view/835)

Новых полноценных референсных диапазонов нет. В статье [Лобыкиной и соавторов](https://mednauki.ru/index.php/MK/ru/article/view/1378) границы 25(OH)D взяты из рекомендаций РАЭ 2016 года и используются для описания распространённости. Порог высокомолекулярного адипонектина требует установленного абдоминального ожирения. Работы по агрегации тромбоцитов, D-димеру, лептину и гормонам описывают специальные когорты или протоколы. Кроме двух описаний выше, правила с проверяемыми общими условиями не добавлены. [Адипонектин](https://www.sci-notes.ru/jour/article/view/797), [агрегатометрия](https://www.sci-notes.ru/jour/article/view/1292), [D-димер](https://www.sci-notes.ru/jour/article/view/979), [лептин](https://mednauki.ru/index.php/MK/ru/article/view/757)

## Проверка

- Миграция `0082-russian-journal-candidates` прогнана в транзакции с откатом, затем применена через запуск локального backend. Сверены 60 записей, два опубликованных источника, три показателя и связи условий.
- 20 синтетических проверок через API покрыли строгие границы 50% и 300 мкг/л, альтернативную единицу ферритина, отсутствие одного из показателей, пол, возраст и независимое срабатывание двух интерпретаций. Синтетические результаты удалены. PDF-файл с четырьмя тестовыми строками подтвердил распознавание трёх новых показателей и отдельное распознавание трансферрина.
- 480 тестов сервера прошли. Предметная сверка выполнена по опубликованным источникам. Отдельной проверки клиническим специалистом не было.
- При откате после остановки backend с миграцией удалить только две созданные интерпретации с условиями и связи этих условий, затем два пороговых интервала, возрастные связи и 60 новых записей журнала по URL/DOI. Названия показателей и связи единиц удалять только при отсутствии измерений и других зависимостей. Корневым источникам восстановить комментарии задачи 0044, затем удалить маркер миграции.
