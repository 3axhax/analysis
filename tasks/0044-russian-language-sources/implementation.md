# Русскоязычные исследования

Миграция `0081-russian-language-sources` зарегистрирована и применена в локальной PostgreSQL. Журнал разбора ведётся в `medicalSource`. Из шести публикаций пять имеют статус `ANALYZED`, одна — `REJECTED_LICENSE`. Четыре добавленных журнала имеют статус `PARTIAL`, поскольку проверено по одной публикации из их каталогов.

## Проверка и откат

- Проверены SQL в транзакции с откатом, запись миграции, 36 строк интервалов и публичность двух статей. Локальный API отвечает на `/health`.
- 58 синтетических проверок через сохранение и получение результата покрыли все 12 диапазонов, граничные значения, проверки пола и возраста, преобразование гемоглобина из г/дл и отсутствие пересчёта для VITROS из нг/мл. Удалены только созданные для этих проверок результаты.
- Все 480 тестов сервера прошли. PDF-парсер различает RDW-SD и RDW-CV, в том числе написания `RDW SD` и `RDWSD`.
- Выполнена сверка с опубликованными источниками. Отдельной проверки клиническим специалистом не было.
- Для отката сначала остановить версию backend с миграцией 0081. В одной транзакции убрать интервалы и возрастные связи двух источников по их URL, затем записи шести статей и пустые корни, созданные этой миграцией. Удалять новые записи возрастов, пункт RDW-SD, переводы и связи единиц только после проверки отсутствия зависимостей. Удалить маркер 0081 после отката данных. Сохранённые измерения остаются в БД.

## Продолжение по каталогам PARTIAL — 23.11.2026

На момент сверки в локальном журнале было восемь корневых записей `PARTIAL`. Поиск охватил PubMed Central, Oxford Academic, список публикаций CALIPER, лабораторный справочник University of Iowa и четыре русскоязычных журнала из этой задачи. Кандидатов сверяли с имеющимися записями по URL и DOI. Например, детский NLR из PMC12927209 уже был внесён, а педиатрическая сводка Iowa уже отклонена по лицензии. Поиск по русскоязычным журналам не дал новых кандидатов для импорта в этой выборке. Полнота каталогов не подтверждена, статусы восьми корней остаются `PARTIAL`.

Миграция `0083-partial-catalog-review` добавила четыре записи журнала. Три статьи о детских референсах получили `REJECTED_LICENSE` из-за CC BY-NC-ND 4.0. Причина и DOI записаны в `medicalSource`.

- [Метаанализ педиатрических референсов гемоглобина](https://pmc.ncbi.nlm.nih.gov/articles/PMC12239707/).
- [Педиатрические референсные и оптимальные кривые гемоглобина](https://pmc.ncbi.nlm.nih.gov/articles/PMC13316602/).
- [Возрастные интервалы печёночных тестов у детей в Иране](https://doi.org/10.1002/jcla.24995).

Из [исследования Marpaung и соавт.](https://pmc.ncbi.nlm.nih.gov/articles/PMC12347179/) (CC BY 4.0) внесены 36 референсов сывороточного креатинина, по одному для каждого пола и каждого полного возраста от 0 до 17 лет. Использованы P2.5 и P97.5 таблиц 1–2. Например, для мальчиков 1–<2 лет верхняя граница в таблице 1 равна 0,83 мг/дл, а в тексте после рисунка 2 приведено 0,60 мг/дл. Приоритет отдан таблицам. Это непрямая оценка по данным профилактического скрининга трёх регионов Индонезии, метод Abbott Architect, IDMS. Внешней валидации в исследовании не было. Региональные медианы, формулы СКФ и отдельные пользовательские интерпретации не добавлялись.

Исходные числа в миграции записаны в мг/дл и при вставке умножаются на 88,4 без дополнительного округления. В БД используется существующая единица мкмоль/л. Каждая возрастная группа занимает принятую в сервисе полосу в 360 дней, начиная с нуля. Порог 18 лет не включён. [Коэффициент преобразования NIDDK](https://www.niddk.nih.gov/research-funding/research-programs/kidney-clinical-research-epidemiology/laboratory/glomerular-filtration-rate-equations/adults).

Проверены 108 строк интервалов, 18 возрастных связей, два пола, маркер и публичность статьи. Прошли 288 синтетических SQL-проверок ниже, на и выше границ в первый и последний день каждого возраста. Backend ответил HTTP 200, сборка и 480 серверных тестов прошли. Сквозная проверка с сохранением результата и отдельная проверка клиническим специалистом не выполнялись.

Для отката остановить версию backend с миграцией 0083. В одной транзакции удалить 108 интервалов и 18 возрастных связей источника PMC12347179, затем четыре записи журнала по URL из этого раздела и маркер 0083. Общие возраста сохраняются. Проверка удаления завершилась откатом транзакции, локальные данные миграции сохранены.
