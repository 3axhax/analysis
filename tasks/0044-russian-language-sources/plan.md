# Русскоязычные исследования

Проверить шесть отобранных исследований. Зафиксировать в `medicalSource` права, происхождение данных, группы, метод и решение. Загружать собственные интервалы как отдельные источники с точным возрастным охватом. Условия для интерпретаций проверять по действующим полям результата и первоисточникам.

Ветка основана на задаче 0043, которая добавляет пролактин. Сверить существующие показатели, измерения и единицы по справочникам. Проверить миграцию в транзакции с откатом, затем проверить применённые строки, возрастные и числовые границы и ссылки источников через локальный API. При откате удалять добавленные интервалы и связи, сохраняя справочные записи, на которые ссылаются результаты.
