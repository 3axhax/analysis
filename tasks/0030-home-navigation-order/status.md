# Статус
- Подготовка — принят: локальная резервная копия создана и проверена, содержимое не публикуется. Несвязанные изменения сохранены.
- Перестановка и проверка — в работе.
- Перестановка — принят: загрузка перед списком в общем массиве навигации.
- Проверка — принят: build/postbuild, lint и diff --check прошли; прежние предупреждения сборки сохранены.
- Уточнение: перестановка разделов страницы — в работе. Предыдущая реализация затронула только меню, теперь переносится и каталог после формы.
- Перестановка разделов — принят: каталог теперь после формы загрузки; вступление остаётся первым. Проверены build/postbuild, lint и фактический порядок секций в HTML.
