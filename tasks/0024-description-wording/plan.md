# Формулировки интерпретаций

Удалить повторяющиеся вводные «возможно», «возможна», «возможны» из текстов интерпретаций, включая общие и источниковые описания; сохранить заголовок «Возможные причины» и общее предупреждение о справочном характере результата. Не менять пороги, условия, связи или источники. Грамматически значимые слова вроде «нет возможности» и «среди возможных причин» не являются вводными.

Подготовить точечную миграцию с контролем исходных текстов, проверить список изменений и dry-run с откатом. Перед применением — проверяемая резервная копия и явное подтверждение; миграцию выполнять атомарно с маркером. Проверить число строк, неизменность связей и условий, работу обычного API на синтетических данных. Откат изменений текстов требует отдельного согласованного обслуживания. Не обращаться к сохранённым пользовательским результатам.
