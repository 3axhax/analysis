# Подготовленное изменение

Миграция удаляет вводные «возможно», «возможна», «возможны» из 40 существующих общих и источниковых описаний; связанные показатели, условия, источники и общее предупреждение не меняются. Внутренние употребления «нет возможности» и «среди возможных причин» сохраняются, как и отдельные смысловые формулировки «может».

Для каждой строки проверяется хеш исходного текста; при изменениях в справочнике миграция полностью прервётся. После подтверждения применены миграции 0043 и 0044: дополнительно найдены 11 описаний с формой «возможен» или начинающихся с обозначения витамина. Всего изменено 51 описание. Обе миграции зарегистрированы, dry-run до применения прошёл с откатом. Профильные тесты и сборка сервера прошли; API проверен на синтетическом результате, число условий — 318. Предупреждение не менялось.
