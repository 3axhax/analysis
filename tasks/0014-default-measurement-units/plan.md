# Единицы по умолчанию в форме

## Цель
Для показателя автоматически выбирать единственную или первую разрешённую единицу без дополнительных кликов. Пользователь и распознанная единица имеют приоритет. При отсутствии разрешённых единиц значение не придумывать.

## Текущая реализация и решение
`AnalysisPointSelectedItem.tsx` инициализирует единицу пустой строкой; PDF reducer сохраняет нераспознанные единицы пустыми. Выбирать первую единицу в форме и синхронизировать существующие значения в Redux, не меняя matcher или золотые fixtures. Для PDF-показателя без распознанной единицы обозначить автоматический выбор и предложить проверить его по бланку; не показывать выбор как распознанное написание. Ручной выбор и распознанная единица не перезаписываются. На API отправлять существующий контракт без служебного признака формы.

## Проверка и риски
Синтетические тесты: одна и несколько единиц, выбор пользователем, ручной ввод, распознанные/отсутствующие единицы PDF, асинхронные справочники, повторный рендер и пустой список. Client lint/build; медицинская достоверность зависит от проверки единицы по бланку. Сервер, БД, PDF matcher и исходные данные пациентов не изменяются.
