# Реализация

Форма автоматически выбирает первую разрешённую единицу; при единственном варианте она отображается без дополнительного действия. Ручной выбор и распознанная единица сохраняют приоритет. Если для PDF-значения единица не распознана, подставляется первый вариант, но в форме показывается просьба сверить его с бланком; источник/текст распознанной единицы не выдумывается. Служебная отметка автоопределения остаётся в состоянии клиента и не передаётся в API. При отсутствии единиц значение не назначается.

Парсер, сервер и БД не изменены. Полный набор клиентских тестов: 16 тестов прошли, включая 6 сценариев единиц с синтетическими данными; сборка и lint клиента прошли. В отдельном синтетическом предпросмотре проверены единственная единица, первый вариант из нескольких и ручное переключение; временные файлы удалены. Коммерческий сайт не изменялся.
