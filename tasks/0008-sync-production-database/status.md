## Повторная синхронизация, 07.11.2026 — в работе
По запросу пользователя актуализировать локальную БД из production. Ветка main совпадает с origin/main; незакоммиченный title сохранён. Production содержит migrations 0010–0015, локальная БД — нет. План: read-only экспорт production во временный закрытый файл, восстановление в отдельную локальную staging DB, проверка доступности схемы/маркеров/ограничений/агрегатов; затем переключение локальной БД с сохранением прежней базы до проверки и удаление временного файла. Производственная БД не изменяется. Дополнительные резервные копии не создавать согласно прежнему явному запрету пользователя. Результаты, пользователи и sessions являются чувствительными: не выводить и не фиксировать их содержимое.

Экспорт production во временный локальный файл отклонён автоматической проверкой: полный состав включает потенциально чувствительные результаты, пользователей и session tokens; общее поручение признано недостаточным явным разрешением на состав и локальное хранение. Архив не создан, БД не изменены, staging не начат. Нужна явная позиция пользователя по переносу полного состава и локальному временному хранению либо выбор ограниченного набора данных. Дополнительный backup запрещён предыдущим указанием пользователя.
