# Реализация

Согласованные шесть числовых условий коэффициента де Ритиса закреплены в коде: ≥2, ≥1,7, =1,5, =1, <1 и <1,5. Все подходящие условия срабатывают независимо, в том числе одновременно. Референс 0,91–1,75 и вычисляемый по нему статус остаются отдельными: например, значение 1,72 может иметь нормальный статус и подходить под условие ≥1,7. Сравнение выполняется по исходным значениям АСТ и АЛТ без предварительного округления; нулевой АЛТ исключает расчёт.

Миграция 0042 добавляет стабильные ключи условий и описания в локальную БД. Тексты доступны для редактирования в админке, числовое условие показано отдельно и защищено от изменения через обычную форму. В результате условие также отображается рядом со статусом показателя. Описания ограничены общим источником и не подменяют правила других источников.

Перед применением создана и проверена резервная копия локальной БД. Транзакционный dry-run завершён откатом, после чего миграция применена с маркером. Проверены границы, пересечения, вычисление и административное редактирование: 53 набора и 438 тестов backend прошли; сборки backend и client и lint client прошли. Проверка обычного HTTP API осталась незавершённой: работающий сервер не отвечал, а доступ к Docker был недоступен для проверки и безопасного перезапуска. Данные результатов в ходе диагностики не выводились.

После восстановления доступности сервера подтверждены health HTTP 200 и маркер миграции 0042. Обычные save/get проверены на трёх синтетических результатах, включая пересечения числовых условий и нормальный статус при выполнении условия ≥1,7. Проверка прошла.
