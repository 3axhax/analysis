## Импорт

Миграция 0073 добавляет два дочерних документа корня ID 3. Для церулоплазмина используются существующие общие интервалы в мг/дл, по отдельной карточке на LOW и HIGH. Для нового показателя «Витамин C (плазма)» используется имеющаяся единица мкмоль/л и алиасы с явным указанием плазмы. Возрастная группа для порога в таблице 19.1 не задана, применяется правило сервиса для всех возрастов. Порог <11 мкмоль/л импортирован как односторонний LOW с исключённой границей для обоих полов. При 11 и выше этот набор статус не назначает. Остальные категории таблицы частично вложены друг в друга и имеют другой клинический смысл, поэтому полноценный диапазон из них не формировался.

Независимой предметной проверки специалистом не было.

Пробная транзакция выполнена с откатом. Затем локальный backend применил 0073. Подтверждены два документа, две записи LOW одного порога для обоих полов, три описания и три условия. Прошли семь синтетических сценариев через HTTP, проверка публичного справочника, TypeScript и 467 серверных тестов.

## Импорт критериев после добавления показателей

Миграция `0075` добавила три дочерние записи корня ID 3. Возраст ограничен взрослыми по правилу сервиса (от 6480 дней). Для D это ограничение внедрения, а не заявленная авторами возрастная граница. Импортируются только подтверждённые односторонние пороги. Ровно на границе и между крайними порогами источник статус не назначает.

| Показатель | Условие | Интерпретация |
| --- | --- | --- |
| Общий сывороточный 25(OH)D | LOW <30 нмоль/л или <12 нг/мл; HIGH >125 нмоль/л или >50 нг/мл | При LOW связь с риском нарушения минерализации костей |
| Сывороточный α-токоферол | LOW <11,6 мкмоль/л | Возможное снижение при нарушении всасывания жиров, в том числе при холестазе |
| Сывороточная медь | LOW <10 мкмоль/л | Возможное снижение при выраженном дефиците меди и наследственных нарушениях её обмена |

Для 25(OH)D взята колонка IOM из таблицы 18b.4, пороги сверены с [отчётом IOM](https://www.ncbi.nlm.nih.gov/books/NBK56050/) и [таблицей NIH ODS](https://ods.od.nih.gov/factsheets/vitaminD-healthProfessional/). Промежуточные категории и колонка Endocrine Society 2011 не импортированы. Порог E взят из §18c.7.1, где отдельно указано ограничение для взрослых. Предпочтительный забор натощак описан в главе как способ уменьшить влияние липидов. Отношение к общему холестерину из §18c.7.2 не соответствует заведённому отношению к сумме липидов. Нижняя граница меди взята из §24b.1. Источник меди выделен отдельно от прежних карточек церулоплазмина, чтобы взрослое ограничение применялось только к новому порогу.

Другие кандидаты остаются без новых правил: EGRAC зависит от исключения дефицита G6PD, которое сервис не может проверить. Для цинка отсутствуют условия забора, для тиаминдифосфата глава не выбирает единый порог, пороги фолата и йодурии из разобранных таблиц предназначены для популяционной оценки. Для E и меди добавлены только непосредственно указанные в главах единицы. Независимой предметной проверки специалистом не проводилось.

Пробная транзакция откатилась. Миграция применена при штатном запуске локального backend. Проверены 12 строк порогов для обоих полов и три карточки, а также сохранение двух прежних карточек церулоплазмина. Прошли 15 синтетических HTTP-проверок, 476 серверных тестов и TypeScript.

## Дополнительные пороги и единицы

Миграция `0076` применена локально. Для взрослых добавлена категория возможной недостаточности 25(OH)D: 30–<50 нмоль/л и 12–<20 нг/мл. Границы сверены с [таблицей NIH ODS](https://ods.od.nih.gov/factsheets/vitaminD-healthProfessional/). Существующие крайние пороги сохранены. Обе нижние градации используют статус LOW и разные пояснения.

На самой границе или ниже этот источник статус не присваивает. Показатель вводится как результат измерения, автоматического расчёта нет.
