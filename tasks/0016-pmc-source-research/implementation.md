# Результат поиска

Подготовлены предложения в `proposals.md`: три источника, правила, тексты, лицензии, происхождение и ограничения. В БД и приложении изменений нет. Проверены общедоступные тексты и лицензии публикаций, справочник показателей и интервалы только чтением. Правила щитовидной железы требуют выяснения единиц FT3/FT4, все кандидаты требуют предметной проверки до загрузки.

## Перенос в локальную БД

Журналируемая миграция 0015 добавляет три статьи PMC, восемь описаний и 16 условий. Для MCV заданы нормативы 82–98 фл для взрослой группы обоих полов, гемоглобин и гормоны явно наследуют общие нормативы. Метаданные ограничивают источники ageId текущего u18y; в расчёте источников добавлена проверка этого ограничения. Единицы и нормативы Т3/Т4 оставлены как есть по указанию пользователя; расхождение единиц не подтверждено как опечатка в статье. Изменения старых описаний и норм не выполнялись.

Миграция прошла SQL в транзакции с откатом и затем применена штатным startup-механизмом. Проверены counts, backend build, 14 тестов, семь синтетических HTTP-случаев границ/пола/детей/пропусков и четыре сочетания гормонов. Создано 11 синтетических результатов без сохранения идентификаторов в документации. Точное 18-летие в 360-дневной модели равно 6480 дням, тогда как текущая группа u18y начинается с 6481 дня: без отдельного изменения возрастного справочника или модели область применения на этой границе не полностью соответствует согласованной. Медицинской проверки специалистом нет. Автоматический rollback миграции отсутствует; откат требуется готовить отдельно с сохранением связанных данных.
