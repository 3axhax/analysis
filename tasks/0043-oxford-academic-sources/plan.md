# Oxford Academic

Проверить десять публикаций издателя, фиксируя лицензию, метод, популяцию и применимость данных в `medicalSource`. Импортировать проверенные интервалы отдельными источниками. Существующие нормы и результаты сохраняются.

Использовать модель задачи [0037](../0037-overlapping-age-ranges/implementation.md) для возрастных ограничений и журнал задачи [0042](../0042-medical-source-analysis-log/implementation.md). Для подходящих диапазонов сохранить исходную таблицу, единицы и ограничения. Внести новый показатель только с однозначными фразами распознавания.

Проверить миграцию в транзакции с откатом, затем сверить число записей и статусы на и вокруг границ. При откате удалить только добавленные этой миграцией интервалы и источники. Справочные строки, на которые уже ссылаются результаты, сохранить.
