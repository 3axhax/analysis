# Реализация

Описание заболеваний сердца теперь выводится при точном коэффициенте 1,7. При 1,5 оно больше не срабатывает; при 1,7 одновременно действует существующее условие ≥1,7. Название внутреннего ключа `eq_1_5` сохранено для совместимости с существующей записью БД, его исправленный порог и подпись заданы в коде. Данные БД и медицинский текст не изменялись.

Пройдены 49 профильных тестов, сборки backend и client, lint client. Четыре синтетических случая через обычные save/get проверили 1,5, значения непосредственно ниже и выше 1,7 и точную границу. `git diff --check` выполнен.
