# Отображение нескольких интервалов

## Цель и границы

Показывать в таблице результатов все применимые референсы NORMAL/OPTIMUM по возрасту, полу и единице, даже если значение вне них, а рядом со значением — все совпавшие статусы с учётом источника. Фильтр таблицы независим от фильтра интерпретаций и группируется по корневому источнику; общие данные можно исключить. Выводить источник через существующую подсказку. Для каждого документа OPTIMUM подавляет NORMAL только при одновременном попадании; LOW и HIGH остаются. При пустом выборе таблица пуста.

## Текущее состояние и решение

`server/src/interval/interval-reader.service.ts` загружает подходящие по показателю интервалы, но возвращает только совпавшие; `interval-result-read.service.ts` формирует один статус и общий референс. Расширить ответ отдельным списком применимых референсов и данными об источниках, сохранив существующие поля и расчёт описаний. Для каждого источника и статуса предпочитать точную единицу, иначе однозначное преобразование в единицу ввода. Не выводить непроверенные преобразования и не менять данные БД. Клиент использует отдельный фильтр и выводит интервалы и совпавшие статусы, не сливая разные документы.

## Этапы и проверка

1. Добавить тесты API на возраст, пол, несовпадение значения, точную и конвертируемую единицу, конфликт правил и источники; реализовать выдачу.
2. Добавить клиентские тесты форматирования границ, порядка OPTIMUM/NORMAL, подавления статусов, источников и независимости фильтров; реализовать интерфейс.
3. Проверить backend/client build, тесты, lint и синтетический HTTP, не раскрывая данные и ссылки. БД не изменять; до перезапуска backend проверить backup и отсутствие новых startup migrations. Выполнить git diff --check и статус.

Риски: неверное отображение единиц, открытых границ и происхождения источника может исказить медицинский смысл; статусы/условия и исходные значения не менять. Миграция и откат БД не требуются. Изменение приёмки отдельной задачи об отображении не затрагивает существующие пользовательские изменения.
