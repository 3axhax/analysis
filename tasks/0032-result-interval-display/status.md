# Статус

## Подготовка — в работе

Создана и проверена резервная копия локальной БД вне каталога задач. Подтверждены текущие зависимости API и двух фильтров источников; реализация не завершена.

## API и интерфейс — в работе

Добавлены применимые референсы NORMAL/OPTIMUM независимо от значения и метаданные источников. Приоритет точной единицы и преобразование проверяются для каждого документа и статуса; нецелые преобразования, потребовавшие округления, отмечаются как приблизительные. Добавлены независимый фильтр таблицы, группировка по документам, точные операторы границ и подавление NORMAL только при совпавшем OPTIMUM того же документа. Сквозной синтетический запрос к локальному API подтвердил внешний референс и источник при значении вне диапазона. Изменения БД и миграции не выполнялись.

Клиентские тесты покрывают пересечения статусов, приоритет оптимума, отдельные статьи одной группы, источник, независимые фильтры, пустой выбор и отсутствие подходящего интервала. Backend-тесты покрывают выбор единиц и отклонение неоднозначных преобразований. Итоговые проверки и ручной smoke остаются в работе.

## Проверка — принят

Завершены API и интерфейс, включая согласованные правки: селект внутри рамки таблицы и горизонтальные разделители референсов. На синтетической странице визуально проверены расположение, разделитель и фильтр. Прошли 203 целевых backend-теста, 33 клиентских теста, сборки, проверки типов и lint. Синтетические запросы к работающему API подтвердили выдачу внешнего референса вне диапазона и статуса с источником; индивидуальные значения и ссылки не выводились. Агрегаты интервалов и связей не изменились, миграций БД нет. Результат ожидает приёмки пользователя.

По дополнительной просьбе добавлен курсор-указатель для крестиков удаления источника и очистки выбора. Проверены lint, сборка клиента и три теста фильтрации.

По следующему замечанию красная подсветка крестика источника заменена лёгким затемнением в цвет селекта. Проверены lint, сборка клиента и тесты таблицы.

Пользователь принял задачу. Итог реализации и проверки зафиксированы в `implementation.md`; публикация на production не выполнялась.
