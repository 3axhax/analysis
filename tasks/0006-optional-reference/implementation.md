# Сохранение без обязательного норматива

## Итог 2026-10-16,14:13 UTC+05:00

Реализация завершена после отдельного разрешения пользователя на CHECK. SaveResult выполняет только технические проверки point/unit/value/структуры, затем атомарно сохраняет каждую исходную строку с точными sourceValue/sourceUnitId/sourceUnitText. Поля calculation/rule/reference у новых записей null. Наличие диапазона, корректность интервала и возможность конверсии при save не проверяются. Неизвестные ID/нечисловые значения/дубликаты дают явную техническую ошибку всего запроса; молчаливого фильтра строк нет.

GET анализирует source-only по текущим правилам и нормативам. Для отсутствующего/конфликтующего интервала строка сохраняется в ответе с исходными value/unit/text, min/max/status=null и interpretationWarning. Описания не используют этот показатель как NORMAL/LOW/HIGH. Остальные строки анализируются независимо. UI показывает «Нет подходящего норматива» и «Нет интерпретации», но значение и единицу не скрывает. Старые legacy-строки читаются как прежде с нормализацией, а старые расчётные snapshot — по сохранённому коэффициенту/диапазону. GET остаётся read-only. Новые source-only результаты не являются зафиксированным историческим расчётом: повторный GET использует текущий справочник; старые snapshot сохраняют историческую семантику.

## История промежуточной реализации

Ниже сохранено описание этапа до разрешения DDL; утверждения о незавершённости/непереключённом save относятся только к нему.

До отдельного разрешения изменения CHECK выполнена только независимая часть. sourceMeasurementValue технически проверяет исходное число без normative lookup и сохраняет точный decimal. isSourceOnlyMeasurement отличает строки без интерпретации от повреждённых исторических снимков. ReadResult умеет вычислять интерпретацию source-only строки при выдаче, а при отсутствии/конфликте диапазона возвращает исходные value/unit/text и явный null status/bounds, не исключая строку. Исторические snapshot по-прежнему проверяются по сохранённым коэффициентам.

Подготовлены server/scripts/migrations/0006-source-measurements.sql и .down.sql: одна новая source-only ветка существующего CHECK, без новых столбцов и без изменения строк. Up/repeat/down на копии и применение локально НЕ выполнялись, пока нет отдельного точного подтверждения. Down должен отказывать при наличии source-only данных. Backup БД создан/проверен заранее вне tasks.

Backend183tests/19suites, build и read-only ESLint успешны. Новые тесты покрывают mixed result без пропуска строк, source-only read, различение повреждённого provenance, ноль/запятую/точный decimal и технически невалидные значения. БД/Python/gold не менялись; пользовательская форма не отправлялась. Save пока остаётся прежним, блокировка при отсутствующем нормативе ещё НЕ устранена.
