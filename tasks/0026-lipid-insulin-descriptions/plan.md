# Исправление описаний № 99 и 110

По прямому указанию пользователя добавить в список причин повышения холестерина пункт о гипотиреозе из методички, стр. 43, и заменить в описании снижения инсулина склеенный текст на точную формулировку «инсулино-дефицит витаминов группы Ва». Другие тексты и условия не менять. Референсы глюкозы и липидограммы по решению пользователя оставить действующими.

Подготовить транзакционную миграцию с проверкой хешей и условий, использовать проверенную за текущий рабочий день резервную копию, выполнить dry-run с откатом, применить адресные обновления, проверить маркер, тексты и сохранность условий; зарегистрировать миграцию и проверить сервер. Сохранённые результаты не просматривать. Откат изменений БД выполнять только отдельно согласованным обслуживанием.
