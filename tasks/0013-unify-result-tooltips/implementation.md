# Реализация

Общий `InfoPopover` использует InformationCircleIcon и единое оформление подсказки. При наведении и фокусе показывает краткий текст, при клике закрепляется; закрывается повторным кликом, кликом снаружи или Escape. Его используют подсказки описания показателя, значения в расчётных единицах и сведения об источнике. У источника сохранены подробности документа и ссылки. Для подсказки возле названия показателя карточка выравнивается по левому краю, для остальных — по правому.

API, БД и данные результатов не менялись. Четыре синтетических клиентских теста прошли, client lint и build прошли. На временном синтетическом экране проверены иконки, обе карточки и закрытие снаружи; временные файлы удалены.

## Автораскрытие источника
Только для подсказок внешних источников три секунды непрерывного наведения на саму иконку раскрывают и закрепляют полную карточку. Уход с иконки, клик и размонтирование отменяют ожидающий таймер; после раскрытия карточка закрывается обычными способами. Синтетические тесты проверяют 2999/3000 мс, отмену, закрепление и отсутствие автоматического раскрытия обычных подсказок; сборка и lint клиента прошли.
